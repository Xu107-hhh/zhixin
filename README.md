# 执信 ZhiTrust · Anker 售后接稳 Agent（预赛演示）

安克首届黑客松 2026 · 智能服务赛道 · 队伍「执信 ZhiTrust」的可交互演示。

**在线体验**：本仓库即 GitHub Pages 部署源，打开本页面的 `index.html` 路径即可（仓库首页右上角 Settings → Pages 有访问地址）。

## 怎么玩

- 默认**规则演示**模式：判定引擎确定性运行，零幻觉、可复现
- 四个预置场景卡：愤怒客诉·换货全链路 / S1 Pro 同名消歧 / 非授权+超保边界 / English 全英文同链路
- **欢迎自由输入乱试**：订单号（如 ORD-88291）、乱编订单号、发英文、修改预填台词——都会被真实处理
- 对话中点右上角**「处理过程」**：每一步判定与证据实时可见（情绪分档与策略联动 / 质保证据链 / 知识库引用 / 人工确认门）

## 本地运行

```bash
python -m http.server 8791
# 浏览器打开 http://127.0.0.1:8791
```

零构建、零依赖，双击 `index.html` 也可运行。

## 技术一览

纯前端三层：`engine.js`（判定引擎：情绪分档 / 意图 / 质保四象限 / 消歧状态机——判定权不在 LLM 手里）· `app.js`（对话台 + 处理过程抽屉）· `data.js`（自造样例数据层，字段结构对齐官方资料包，入围后整文件替换）。LLM 增强模式可在设置里配置 OpenAI 兼容端点（Key 只存本机 localStorage，不上传）。
